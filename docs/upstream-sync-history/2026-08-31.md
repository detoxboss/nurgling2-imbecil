## Semantic decisions

- **Combat HUD:** adopted upstream's current `NCombatData`-based HUD architecture as the structural
  base for `NFightsess.java`, retiring the fork's older altbuffs/altrelbuffs opening-highlight
  rendering. The Combat Reactor's protocol-level dispatch hooks
  (`Fightsess.requestUse`/`releaseHeld`, `NFightsess.requestAction`/`releaseAction`) were re-grafted
  onto the new HUD class rather than kept with the old one — see
  `docs/fork-customization-ledger.md`'s Combat Reactor entry.
- **Action Search:** retired the fork's own focus patch in `GameUI.java` in favor of upstream's
  `MenuSearch.show()` → `focussbox()`.
- **`MapFile`:** preserved the fork's cross-session shared `(ResCache, filename)` lock; took upstream's
  unrelated `Grid.loadmtime()` addition alongside it.
- **Session-scoped persistence:** preserved explicit-session area/scenario persistence
  (`NConfig.writeAreas`/`writeScenarios` with an explicit session argument) and per-session
  explored-area dirty tracking/debounced save/teardown flush (`ExploredArea.saveIfDue()`/`saveNow()`)
  in `NCore.java`/`NGameUI.java`.
- **Session-correct teardown:** preserved `NGameUI.dispose()` disposing `ui.core` (not the ambient
  foreground session) alongside upstream's new peer-position withdrawal logic (independent of the
  dispose target, ran first). Applied the equivalent session-safe resolution in `NMiniMap.java`'s
  `tick()`, alongside upstream's new hold-to-move steering.
- **Tableware protection:** preserved the passive worn-tableware guard
  (`NGItem.wdgmsg("take")`), kept the background `AutoSaveTableware` worker disabled despite
  upstream's new `autoHelperLock`/`autoHelpersDisposed` thread-safety scaffolding around it —
  verified null-safe with the worker left permanently null.
- **Shared registries:** both fork and upstream additions preserved in `NConfig.Key`, `BotRegistry`,
  `messages.properties`/`messages_ru.properties`, and `NSettingsWindow` entries.

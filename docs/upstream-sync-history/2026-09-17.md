## Auto-drink tooltip rationale

Upstream did **not** modify `AutoDrink.java` in this range. Its only touch was the
`qol.auto_drink_tip` tooltip string added to the shared Auto-drink checkbox, and a separate,
Forager-bot-local drinking behavior (`Forager.java`, `fix/forager-bot-drink`) that never references
the fork's `AutoDrink` class. Upstream's tooltip text described upstream's own older behavior
(fixed 51% threshold, paused while any bot runs, waterskin/bucket-only water detection) — none of
which matches this fork's behavior since PR #4 (`fix/autodrink-fix-and-threshold`). The tooltip
was rewritten in both languages to describe the fork's actual behavior instead: configurable
threshold, water detected via the client's DrinkMeter (not limited to the old waterskin/bucket
scan), runs alongside the current action or a running bot without cancelling it, and continues
until stamina is refilled. See the note added to `docs/fork-customization-ledger.md`'s Auto-drink
entry.
